1b.- Cómo se podría conectar un usuario sin tener que meter la contraseña cada vez que se conecta
Cuando conectamos por SSH, normalmente nos pide una contraseña para autenticarnos. Sin embargo, para evitar meter la contraseña cada vez que nos conectamos, podemos usar un sistema de claves. Esto consiste en generar dos claves, una privada que se guarda en nuestro equipo cliente y otra pública que se añade al servidor remoto. Cuando nos conectemos, el servidor verificará que tenemos la clave privada correcta y nos dejará entrar sin pedir nada más. Es muy útil para automatizar accesos y para no tener que recordar o escribir contraseñas constantemente.
